# ⏱ Pomodoro Focus Timer

A simple and modern **Pomodoro Timer App** built with **HTML, CSS, and Vanilla JavaScript**.  
It helps improve productivity using focused work sessions and short breaks.

---

## ✨ Features

- ⏱ 25-minute focus timer
- ▶️ Start / Pause / Reset controls
- 🔔 Alert when session ends
- 📱 Fully responsive design
- 🎨 Clean minimal UI
- 🚀 Lightweight (no libraries)

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
